
# Newton's Law of Cooling using Python

## Project Objective
To investigate the cooling behaviour of water
using Newton's Law of Cooling.

## Mathematical Model

dT/dt = -k(T - Ts)

T(t) = Ts + (T0 - Ts)*exp(-kt)

## Technologies Used
- Python
- NumPy
- SciPy
- Pandas
- Matplotlib

## Numerical Methods
- Analytical solution
- Curve fitting
- Euler method
- Fourth-order Runge-Kutta method

## Project Components
1. Experimental data
2. Mathematical modelling

5. Graphical visualization

## Applications
